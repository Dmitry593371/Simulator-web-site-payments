## 🎯 О проекте

При управлении интернет-эквайрингом и платежными шлюзами ключевая задача продукта — найти баланс между **конверсией (Success Rate)** и **затратами на комиссии**. Дешевые каналы часто дают больше таймаутов и реджектов, а надежные банковские шлюзы снижают маржинальность.

Этот симулятор позволяет в реальном времени просчитать юнит-экономику потока транзакций при разных стратегиях маршрутизации:
1. **Верхнеуровневый сплит трафика:** разделение потока на оплату через СБП и банковские карты.
2. **Умный роутинг (Smart Routing):** автоматическое направление карточного трафика на самый выгодный эквайринговый шлюз.
3. **Каскадный ретрив (Fallback):** обработка таймаутов на лету — при сбое основного канала транзакция мгновенно переводится на резервный шлюз без потери покупателя.

## 🏗️ Архитектура и Логика симуляции

```text
[ Генератор потока транзакций (GMV, Суммы) ]
                   │
                   ▼
       { Сплит: СБП vs Карты }
          │               │
     (СБП канал)     (Карточный поток)
          │               │
          │         [ Smart Routing / Сплит по шлюзам ]
          │               │
          └───────┬───────┘
                  ▼
    [ Модуль стохастических рисков ]
    (Проверка на Timeout и Decline)
                  │
        ┌─────────┴─────────┐
    (Успех)             (Таймаут / Ошибка)
        │                   │
  [ Расчет комиссий ]  [ Каскадный Fallback ]
        │                   │
        └─────────┬─────────┘
                  ▼
   [ Агрегация метрик и Юнит-экономика ]
```

### Ключевые параметры модели:
* **Стохастика статусов:** Каждый шлюз имеет настраиваемые вероятности технического сбоя (`Timeout %`) и банковского/антифрод-отказа (`Decline %`).
* **Динамическая экономика:** Автоматический расчет общего оборота (GMV), итоговой конверсии, расходов на эквайринг в рублях и **эффективной ставки комиссии** на весь успешный оборот.

## 🚀 Быстрый запуск локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone [https://https://github.com/Dmitry593371/Simulator-web-site-payments](https://github.com/Dmitry593371/Simulator-web-site-payments.git)
   cd payment-gateway-simulator
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   ```bash
   streamlit run app.py
   ```

4. Перейдите по адресу из терминала (обычно `http://localhost:8501`).

## 📊 Метрики дашборда

* **Успешный оборот (GMV):** Сумма всех успешно проведенных транзакций.
* **Конверсия (Success Rate):** Доля транзакций со статусом `SUCCESS` от общего потока.
* **Расходы на эквайринг:** Суммарная комиссия, удержанная шлюзами.
* **Эффективная ставка:** Реальная средняя комиссия в процентах на рубль успешного оборота.
